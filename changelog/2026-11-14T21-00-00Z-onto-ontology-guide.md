# Onto's Ontology document: one read before writing

Onto now answers `Ontology`: every type name with a one-sentence description, the
node types each relationship connects (projections are left out because they are
derived), the root node and a short guide to staging a change by address. Its
description starts with "Start here", which the platform's MCP instructions now tell
agents to read once before writing to an app.

In the webapp sidebar evals, agents read it on every edit and used about half the
tokens; organization edits passed 6 of 6.
