# Revision-pinned thread context references

The public SDK allows budgeted thread history to name up to four entity snapshots
by installation, type, ID and positive revision. The platform reauthorizes and
loads exact revisions per reply as transient untrusted context. Sources grant no
access and do not establish conversation coverage, replace messages or change
compaction cutoffs. This contract alone does not activate daily project reports
or transcript checkpoints.

Validated with SDK thread contract tests and package type checking.
