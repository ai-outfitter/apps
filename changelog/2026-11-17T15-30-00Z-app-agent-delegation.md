# Opt-in app agents for Ask Outfitter

The public SDK adds `actionAgent`'s `delegation` option and the thread descriptor's
`agent.context` entry point. Onto and Software Foundry opt in, reusing their
existing private conversations and app-owned proposal review. Delegation does
not grant permissions, execute proposals or enable arbitrary-page design review.

Deploy platform descriptor support before these app packages. Synthetic tests do
not establish live-provider execution or installation acceptance.
