# Synthetic Keystone native-apple

This fixture represents the iOS and macOS shell around Keystone Charts. The shared app module presents an installation confirmation screen after dashboard preview and persists dashboards to a local catalog keyed by UID. The test-only repository marker is KEYSTONE_NATIVE_APPLE_FIXTURE.

The fixture has no connection to real Grafana servers or Apple project credentials.

The operator wants the same service installation flow for Forgejo and Grafana from iOS and macOS.
