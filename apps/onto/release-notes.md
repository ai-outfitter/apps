
Migration preparation now inventories every visible personal and organization
owner and captures paginated installation archives privately. Offline Wiki
conversion preserves authored types and refuses partial or lossy migration,
existing destination files, missing endpoint contracts and unmapped history.
These tools do not activate a production cutover.


An explicitly authorized operator can now reconcile legacy relationship contracts
and preserve same-name type identities, migrate each frozen Wiki graph into Onto,
and verify exact destination rows and original history. Source graphs remain
read-only archives. Forward schema migration records immutable lineage and the
original source rows; ordinary portable imports cannot create migration authority.


Changes opens on a full-width graph, with separate proposal and review/anchor views.
Graph canvases support dragging in both directions, wheel/trackpad zoom around the pointer, readable
initial zoom and an expanded view. Open batches support explicit proposal replacement
by ref and anchor edits; undecided member-review batches also allow valid anchor
changes. Mutation results report dry-run validation and ask callers to repair failing
drafts before submission. Submitted operations and member approval remain unchanged.

## Proposal review readability

Structured proposal bodies display labeled fields and lists, while Markdown keeps
its rendered formatting. Reviewers see a batch overview, separate records and
relationships, and the number of distinct sources. Per-proposal reasons and
source citations expand on demand; Onto citations open the referenced record.
The shared managed app shell uses the current platform mini sidebar and account
menu, with navigation metadata supplied by the platform.

Organization pages now use an organization-focused mini sidebar with Home, Wiki,
Workflows, Apps and Settings, the organization identity, and Back to personal.

Change graphs mark new records with a green dot and edited records with a yellow
dot. Context records remain unmarked; hover text also names the change.
