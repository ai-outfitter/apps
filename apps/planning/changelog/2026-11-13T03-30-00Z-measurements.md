Goals' metrics can now be recorded from connectors. A Measure in the Wiki says how to compute a MetricDefinition from a read-only connector operation (PostHog `query.run`, GitHub `repositories.read`); `RecordMeasurements` and the weekly `record-measurements` workflow store one Measurement per window, and `MetricMeasurements` returns each metric's latest and previous value and the change, for example this week's GitHub stars and growth since last week. Organization progress shows a KPI's latest value instead of "Not connected" once one is recorded. The unused measurement snapshot stubs are removed; see `docs/measurements.md`.
