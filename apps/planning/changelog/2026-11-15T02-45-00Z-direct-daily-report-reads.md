Planning now records which Wiki document it wrote each daily report to (`planning_report_notes`, written when the report is saved). `DailyReport` and `DailyReports` read that document directly: one call to the Wiki instead of finding the Wiki, asking it to describe itself, looking the page up by name and then reading it. Reports saved before this change, or whose recorded document can no longer be read, are still found the earlier way. The Wiki document stays the only copy of a report.
